# PrettySmooth

<cp>Optimizes the WHOLE game</c>: main menu, levels and editor. Works on **PC** and **mobile**.

## Presets
- **Vanilla**: the original game.
- **Balanced**: light, almost no visual loss.
- **Performance**: cuts the heaviest effects (shaders, shake, forced LDM, medium textures).
- **Potato**: makes the game <cr>UGLY</c> on purpose to run on anything (low 16-bit textures, 60 FPS lock).
- <cp>**UltraSmooth**</c>: maximum smoothness.

## Options
- **FPS**: custom FPS limit, VSync off (PC), menu frame pacing, high priority and 1ms timer (PC), purple FPS counter.
- **Levels**: particles (normal / reduced / off), shaders, camera shake, glow, forced Low Detail Mode, background, middleground, trails.
- **Menus**: particles, static main menu, fast/instant transitions.
- **Editor**: particles, glow, shader preview, grid, spaced visibility updates.
- **System**: texture quality, 16-bit textures, memory cleanup.

Open the **purple menu** with the <cp>PS</c> button in the main menu, pause menu or editor pause. The menu can be switched to **Portuguese**.

<cy>Note:</c> PrettySmooth can't remove lag with a 100% guarantee. Results depend on your device.
